# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to every project space: issues, pull
requests, discussions and any other channel run by the project.

In short: be respectful and welcoming, whatever someone's background, dialect, region, level of
experience or language. Disagree about code and language data with arguments and sources, never
with personal attacks. Harassment, discrimination and publishing other people's private information
are not tolerated.

KDT brings together contributors who speak different Kurdish varieties and write them differently.
Treat differences in dialect, spelling and script as information to document, not as mistakes to
mock.

## Reporting

To report unacceptable behaviour:

* **Contact the maintainer privately** using the contact details on the maintainer's GitHub profile
  ([github.com/renas94](https://github.com/renas94)).
* **Report content to GitHub** using the "Report content" option on any comment, issue or pull request,
  or through [GitHub's abuse reporting form](https://support.github.com/contact/report-abuse).

Do not report conduct problems in public issues. All reports are reviewed and handled confidentially.

Maintainers who do not follow or enforce the code of conduct may face temporary or permanent
consequences, as decided by other members of the project's leadership.
